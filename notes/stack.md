# 这套东西是怎么跑起来的

一句话：**零依赖静态站**，没有构建步骤，改完文件就是最新的。

## 结构

```
site/
├── index.html          # 唯一的页面骨架
├── assets/
│   ├── style.css       # 全站样式，跟随系统深浅色
│   ├── app.js          # 哈希路由 + 笔记清单
│   ├── md.js           # 极简 Markdown 渲染
│   └── tools.js        # 工具槽位
└── notes/              # 笔记原文，纯 .md
```

## 为什么不用框架

因为只有这么点内容。框架会带来构建、依赖、版本、部署链路——每一样都是以后不想更新它的理由。

现在：加一篇笔记 = 存一个 md 文件 + 在 `app.js` 的 `NOTES` 里加一行。

## 部署

推到 GitHub 仓库，Pages 选 `main` 分支根目录，等一分钟就上线。自定义域名在仓库 Settings → Pages 里填，会自动生成 `CNAME` 文件。

## 备忘

- 图片放 `assets/img/`，笔记里用相对路径引用
- 换域名记得同步改 `index.html` 里的 `description`
- 没有后端，所以别指望做登录、评论这类要服务端的功能
